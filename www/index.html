Robert's Bad Asteroids Game

Description

A (work in progress) version of the Asteroids arcade game.

Sound Warning! The game now has sound effects, but there are no controls on the page for changing the volume (including to mute them). You can mute the browser tab by pressing ctrl + m. Proper volume controls are coming soon.

Controls

Input Effect
W Fire thruster
A Rotate Left
D Rotate Right
Spacebar Shoot gun
